## Why

工作任务使用固定 default 归属，登录校验没有形成数据隔离；现有生活与工作页面不能完成每天 08:30 计划和 21:00 复盘。先建立可信权限及每日闭环，再接入 ChatGPT。

## What Changes

- **BREAKING** 工作 REST、MCP、AI 对话及总结必须携带可信身份；任务、分类、模板、版本、便签和子任务按真实用户隔离。
- 旧 default 数据保留隔离，不自动归属首个登录用户；认领须明确指定账号并审计。
- 新增个人每日计划、任务快照、确认和复盘反馈；聚合工作任务、本人家庭任务及日程。
- 新增北京时间 08:30 / 21:00 调度、持久化幂等和当日恢复补跑。
- 新增适老化“我的一天”入口；保留原任务五值状态及 family_id 校验。

## Capabilities

### New Capabilities
- `work-task-ownership`: 真实用户身份与所有工作数据的读取、写入、AI 和定时执行隔离。
- `personal-daily-planning`: 个人每日计划与复盘、版本校验、隐私过滤及补跑。

### Modified Capabilities
无。原任务状态及家庭共享语义保持不变。

## Impact

task-planner 两个服务、Java 后端、Vue 页面、两套数据库迁移、网关 HTTP/HTTPS 与 Compose。新功能默认关闭，不运行生产迁移或重启业务容器。首版无模型调用：授权任务字段进入确定性排序和快照，输出重点建议；不向外部模型发送数据。

## Non-goals

ChatGPT MCP 对外接入、主动微信通知、自动任务延期、合并数据库、调整现有 22:00 模板学习行为以及生产发布。
