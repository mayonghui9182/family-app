# 公众号自动分类使用说明

向公众号发送任务，例如“明天整理书架，分类设为家庭日常事务”。

系统会优先使用当前家庭的已有分类；没有合适分类时，成年用户可收到新分类建议。候选显示“新建，确认后创建”时，分类尚未落库。核对任务、日期、负责人、分类后，回复该清单给出的“确认创建 版本号”，分类与任务才会一起创建。修改任务后请使用最新版本号确认。

儿童只能使用已有分类或保持未指定。失败不会留下本批新增分类或部分任务；同一确认重试不会重复创建。

当前直接发送微信语音气泡尚不支持。可先用手机键盘听写，将文字核对后发送；接入分析见[语音输入分析](wechat-voice-input-analysis.md)。
