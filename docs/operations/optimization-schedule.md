## 忘记密码一期范围

- 登录页提供“忘记密码？”入口 → 填写注册邮箱 → 统一发送提示 → 邮件链接设置新密码 → 返回登录。使用大字号、明确步骤和返回入口。
- 新增 `POST /api/auth/password-reset/request` 与 `POST /api/auth/password-reset/confirm`；匿名可访问仅这两个接口，不放开其他鉴权。
- 无论邮箱是否存在，申请响应保持一致；限制来源和账号请求频率，限制凭证尝试次数，不在日志或响应中暴露重置凭证。
- 使用高熵随机一次性凭证，数据库只存摘要，15 分钟过期；新的申请使旧凭证失效。用事务/条件更新保证并发只成功一次。
- 重置页清理地址栏凭证，避免第三方资源携带引用地址泄漏。沿用项目密码长度约束，确认新密码一致；重置成功撤销旧 accessToken，要求重新登录。
- 找回属于账号维度，凭证绑定 user_id；不得通过家庭 ID 或成员权限代替邮箱持有证明，也不得修改家庭数据。
- 未配置发信服务时明确提示当前不可用，不展示虚假的“发送成功”。发送失败可重试，配置和凭证不入库。
- 仅手机注册或无法访问邮箱的账号：说明一期不支持该方式，保留返回登录入口；不提供未经身份验证的人工改密接口。
