# 工作隔离与个人每日计划改造

## 当前范围

OpenSpec change：`personal-daily-planning`。本轮完成工作数据权限与“我的一天”基础闭环，未接入 ChatGPT、未发送主动通知、未部署或操作业务数据库。

工作域按真实登录用户隔离；家庭域查询保持 family_id 和实时成员校验。任务仍为固定五值状态。个人记录不依赖当前选择的家庭，不给家庭成员开放私人工作数据。

## 用户行为

- 入口：桌面菜单、首页快捷按钮、更多 → 我的一天，路径 `/daily`。
- 北京时间 08:30 自动生成，用户需主动开启“每天自动生成计划与复盘”。可随时手动生成今日计划。
- 聚合本人家庭任务、可访问的当日日程、本人工作任务；排除草稿和未来到期任务。没有截止日期的待办可纳入。重点最多三项，不推断耗时。
- 可排序、移出今日计划、选择重点、保存并确认；这些操作不修改原任务状态或截止日期。
- 21:00 对照计划复盘，显示实际统计截止时间及今日新建但未纳入计划的事项，允许填写阻碍和明日建议。不能据更新时间推断“今天实际完成”。
- 保存不可变初始项目快照；复盘复制当时计划内容及版本，后续调整不改变已生成复盘。
- 每次读取重新验证任务归属和家庭权限，无权或删除项目只显示不可访问。工作来源失败返回明确错误，不保存为完整空计划。
- 停机后仅补跑当日到期记录。21:00 后才生成的计划不作为早晨基准，不计算完成率。

## 配置与发布边界

`DAILY_ENABLED=false` 为默认值；`DAILY_WORK_URL=http://tp-task-service:8100` 指向内网工作服务。扫描间隔默认 60 秒，启动延迟 30 秒，08:30 当分钟不标为补跑。

工作两个服务新增 `BACKEND_BASE_URL`、`INTERNAL_API_SECRET`，根 Compose 已配置。用户请求向主后端核验 X-Access-Token；内部请求还须明确 X-Work-User-Id 并核验账号有效。网关清除来自外部的内部密钥和用户作用域头，HTTP/HTTPS 均将工作请求转到对应服务；服务直连也认证。

根 Compose 是推荐部署入口。独立 task-planner 编排必须另外提供可达的主后端认证地址和内部密钥，否则业务请求拒绝，不能恢复无认证模式。

生产发布需要独立审批：先备份两库并记录镜像，再在维护窗口协调后端、工作服务和网关升级；不可只升级模型而不迁移工作库。现有容器和库在本轮均未改变。不要使用 test/internal-mock profile 发布。

工作 Alembic `0003` 为任务、分类、子待办、便签、模板、版本、总结日志补归属；旧行保留 default，不自动认领。发布前由用户明确指定旧数据所有者，另行进行有审计的整组认领；不要把首个登录账号当作所有者。原 default 数据不进入新用户列表或自动总结。

后端 Flyway V17 新增 daily_settings、daily_records。开启 DAILY_ENABLED 后仍仅为主动启用用户自动生成。生成持久化记录不等于送达提醒；本轮没有微信或 ChatGPT 主动通知，常开服务才能准点执行。

## 回滚

- 首选关闭 DAILY_ENABLED，保留每日记录表，恢复已验证的安全应用版本。
- 工作库有任何真实用户行时，0003 downgrade 主动拒绝，禁止回退为原共享 default 应用。保留归属及关联数据；不得通过删除列“恢复兼容”。
- V17 仅在其为最新迁移且两表为空时可用 `backend/src/main/resources/db/rollback/V17__Personal_Daily_Planning.sql` 逆向。脚本拒绝有数据回滚。有记录时保留结构，通过关闭功能回滚，不删除用户计划和反馈。
- 不自动迁移、认领、清空或重置现有业务数据。

## 验证入口

- 后端：`cd backend && ./gradlew test --no-daemon`。
- 工作域：`python3 scripts/verify-work-ownership.py`。随机独立 PostgreSQL，正逆向迁移、125 项工作测试、103 项 AI/MCP 测试，认证与 LLM 平台使用测试桩，MCP 和数据库使用真实服务。固定两个测试用户的凭据不属于真实账号。
- 每日 PostgreSQL：`python3 scripts/verify-daily-postgres.py`。回环随机端口新容器，完整 Flyway、八次并发生成只一条、八次同版本确认只一个成功、有数据拒绝逆向及空表逆向后重新迁移。
- 前端：`cd frontend && npm run build && npm run test:unit`。
- 浏览器平台桩：`node scripts/daily-ui-fixture.cjs`，另启前端 `VITE_PROXY_TARGET=http://127.0.0.1:15388 npm run dev -- --host 127.0.0.1 --port 15387`。均只绑定回环；模拟账号、排序、键盘保存和 375px 窄屏用于视觉验收，不验证真实用户数据。

测试脚本只清理本轮标签一致的随机容器、网络及自身临时依赖目录，不连接业务数据库。已有测试数据及其他未提交改动保持不变。
